# Compute N non-zero values from a Poisson distribution with a given MoI

Compute N non-zero values from a Poisson distribution with a given MoI

## Usage

``` r
nzPois(N, moi)
```

## Arguments

- N:

  the number of random variates to return

- moi:

  the mean moi

## Value

a [numeric](https://rdrr.io/r/base/numeric.html) vector of length N

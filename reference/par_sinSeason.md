# Return a list to configure and dispatch seasonalFoI.sin

Return a list to configure and dispatch seasonalFoI.sin

## Usage

``` r
par_sinSeason(phase = 0, pwr = 1, lift = 0, shift = 0)
```

## Arguments

- phase:

  shift the phase / time of year

- pwr:

  raise the seasonal pattern to a power

- lift:

  the amplitude of the

- shift:

  shift everything up or down

## Value

a [list](https://rdrr.io/r/base/list.html)

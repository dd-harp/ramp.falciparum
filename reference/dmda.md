# Compute the derivatives for MoI using a hybrid model

Compute the derivatives for MoI using a hybrid model

## Usage

``` r
dmda(a, M, p, FoI_a)
```

## Arguments

- a:

  the host age

- M:

  the state variables

- p:

  the parameters

- FoI_a:

  a cohort trace function

## Value

the derivatives as a [list](https://rdrr.io/r/base/list.html)

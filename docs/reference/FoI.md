# Force of Infection, \\h\_\tau(a)\\

Given a birth day, \\\tau,\\ age is related to time by the formula \\t =
a+\tau\\. The FoI is computed as \$\$\bar h \\ \omega(a) S(a+\tau)
T(a+\tau)\$\$

## Usage

``` r
FoI(a, FoIpar, tau = 0)
```

## Arguments

- a:

  host age

- FoIpar:

  a compound [list](https://rdrr.io/r/base/list.html) to compute
  \\h\_\tau(a)\\

- tau:

  the host cohort's birthday

## Value

[numeric](https://rdrr.io/r/base/numeric.html)

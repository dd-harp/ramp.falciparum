# Compute the derivatives for MoI and true PR

Compute the derivatives for MoI and true PR

## Usage

``` r
dpda(a, M, par, FoIpar)
```

## Arguments

- a:

  the host age

- M:

  state variables

- par:

  the model parameters

- FoIpar:

  parameters that define an FoI function

## Value

the derivatives, as a [list](https://rdrr.io/r/base/list.html)

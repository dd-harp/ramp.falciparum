# The PDF for non-zero counts, \\\log\_{10}\\ transformed

The PDF for non-zero counts, \\\log\_{10}\\ transformed

## Usage

``` r
d_nz_counts_log(hatxi, xi, bvm = 13, pars = par_nb())
```

## Arguments

- hatxi:

  \\\log\_{10}\\ parasite counts

- xi:

  \\\log\_{10}\\ parasite densities

- bvm:

  blood volume as \\\log\_{10}\\ red blood cells

- pars:

  parameters that define a detection function

## Value

binary detection result

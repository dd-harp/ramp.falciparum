# Compute expected log10 parasite densities, `mu`, as a function of the age of infection `alpha`

Compute mean log10 parasites for a model with no immunity

## Usage

``` r
# S3 method for class 'W'
Fmu(alpha, W, par_Fmu)
```

## Arguments

- alpha:

  the age of a parasite infection

- W:

  the immune tracking variables

- par_Fmu:

  a [list](https://rdrr.io/r/base/list.html) that defines a model

## Value

mean log10 parasite densities

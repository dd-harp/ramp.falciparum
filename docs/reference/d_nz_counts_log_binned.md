# The binned PDF for non-zero counts, \\\log\_{10}\\ transformed

The binned PDF for non-zero counts, \\\log\_{10}\\ transformed

## Usage

``` r
d_nz_counts_log_binned(xi, bins = NULL, bvm = 13, pars = par_nb())
```

## Arguments

- xi:

  \\\log\_{10}\\ parasite densities

- bins:

  breakpoints for summarizing outputs as \\\log\_{10}\\ counts

- bvm:

  blood volume as \\\log\_{10}\\ red blood cells

- pars:

  parameters that define a detection function

## Value

binary detection result

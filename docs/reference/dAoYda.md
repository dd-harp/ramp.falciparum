# Compute the derivatives of the approximate moments of the AoY dynamically

The

## Usage

``` r
dAoYda(a, vars, pars, FoIpar)
```

## Arguments

- a:

  the host age

- vars:

  the state variables

- pars:

  the parameters

- FoIpar:

  parameters that define an FoI function

## Value

the derivatives of the MoI and the AoI as a
[list](https://rdrr.io/r/base/list.html)

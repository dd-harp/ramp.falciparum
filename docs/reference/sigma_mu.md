# A function to compute the variance of the beta distrution as a function of the mean.

A function to compute the variance of the beta distrution as a function
of the mean.

## Usage

``` r
sigma_mu(mu, par)
```

## Arguments

- mu:

  the mean value for the distribution (0 \<= mu \<= 1)

- par:

  parameters to dispatch and configure the instances

## Value

a [numeric](https://rdrr.io/r/base/numeric.html) vector of length(mu)

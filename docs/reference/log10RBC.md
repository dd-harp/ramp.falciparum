# Compute log10 of the red blood cell population

Compute log10 of the red blood cell population

## Usage

``` r
log10RBC(a, par)
```

## Arguments

- a:

  the age of a host cohort

- par:

  a [list](https://rdrr.io/r/base/list.html) of parameters

## Value

a [numeric](https://rdrr.io/r/base/numeric.html) vector of length(a)

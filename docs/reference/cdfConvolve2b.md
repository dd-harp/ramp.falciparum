# The density function for the sum of two infections, method a

The density function for the sum of two infections, method a

## Usage

``` r
cdfConvolve2b(meshX, CDF1, CDF2)
```

## Arguments

- meshX:

  a mesh of host cohort ages

- CDF1:

  the CDF for a complex distribution

- CDF2:

  the CDF for a complex distribution

## Value

a [numeric](https://rdrr.io/r/base/numeric.html) vector of length(meshX)

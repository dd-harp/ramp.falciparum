# Compute the derivatives for MoI using a hybrid model

Compute the derivatives for MoI using a hybrid model

## Usage

``` r
dmda(a, M, p, FoIpar)
```

## Arguments

- a:

  the host age

- M:

  the state variables

- p:

  the parameters

- FoIpar:

  parameters that define an FoI function

## Value

the derivatives as a [list](https://rdrr.io/r/base/list.html)

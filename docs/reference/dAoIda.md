# Compute the derivatives of the AoI moments dynamically

The

## Usage

``` r
dAoIda(a, M, p, FoIpar)
```

## Arguments

- a:

  the host age

- M:

  the state variables

- p:

  the parameters

- FoIpar:

  parameters that define an FoI function

## Value

the derivatives of the MoI and the AoI as a
[list](https://rdrr.io/r/base/list.html)
